Привлечение: итоги первой недели рекламы

С 5 ноября идёт зачётный период. Здесь: приток и DAU по дням, из кого складывается DAU, удержание по когортам, стоимость регистрации и прогноз к 2 декабря.

Приток и DAU по дням

Регистрация происходит при первом запуске приложения. «Живая» регистрация — человек прошёл онбординг и дал данные.

Из кого состоит DAU

Каждый столбец — активные в этот день, разложенные по дню регистрации. Растущая доля старых когорт значит, что накопленная аудитория возвращается, а не держится только на новых показах рекламы.

Удержание по когортам

Доля когорты, вернувшейся ровно на N-й день после регистрации. «Вернулся» — любое взаимодействие с продуктом (в том числе через уведомление, открывать приложение необязательно). Только прошедшие дни.

Стоимость регистрации

Расход взят из отчёта Яндекс Директа за 4–9 ноября. Регистрации и DAU посчитаны за тот же период (5–9 ноября, 4 ноября регистраций не было). Расход можно поправить, цены пересчитаются.

Кампании Директа

Отчёт Директа за 4–9 ноября. «Конверсия» здесь — целевое действие, которое считает сам Директ, это не то же самое, что регистрация в продукте. Привязать регистрации к кампаниям мы не можем: приложение передаёт источник только в сборке 1.0.2.

Прогноз DAU до 2 декабря

Модель: DAU = (регистрации в день) × (доля вернувшихся на N-й день по нашим когортам) + небольшая база до рекламы. Это сценарий, а не обещание: правее D6 данных у нас пока нет, поэтому «долгий хвост удержания» задаётся вручную.

Качество трафика

Воронка онбординга по данным AppMetrica (период 3–9 ноября, 657 человек дошли до первого экрана) и источники установок.

Источник установок по AppMetrica: Yandex.Direct 635 из 662 (96%), органика 27. Разбивки по креативам пока нет: приложение передаёт метку источника только в сборке 1.0.2.

  • Данные: боевая база продукта, срез на момент, указанный вверху. Исключены разработчики и тестовые аккаунты.
  • DAU — число людей с любым взаимодействием за день по московскому времени (так же, как в зачёте). По открытиям приложения (AppMetrica) цифры около 20–30% ниже: часть людей пользуется только утренним сообщением из уведомления.
  • Регистрации ≈ установки с первым запуском; установки из стора, которые не были запущены, сюда не попадают.
  • D7 по рекламным когортам появится после 12 ноября: первая когорта созревает в этот день.
