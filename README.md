## Что это

Каждое утро — одна фраза о том, чего ждать от дня. Не «высыпайся и отдыхай», а конкретный прогноз, построенный на паттернах из твоего сна, шагов и экранного времени за последние недели.

Данные собирает WorkManager в фоне — ты не трогаешь приложение. Прогноз строит LLM ночью. Утром читаешь одно предложение.

---

## Как работает

```
Ночь: WorkManager → Health Connect + UsageStats → POST /data/passive
Утро: LLM смотрит на последние 7 дней → одна фраза → push-уведомление
День: три кнопки в шторке уведомлений → «норм / так себе / тяжко»
Неделя: «Разбор недели» — что изменилось и почему
```

**Никаких форм.** Никаких напоминаний заполнить что-то и никаких дневников настроения.

## Как это устроено

### Откуда берутся данные

Телефон и так всё это считает — приложение смотрит на то, что уже записано: сколько времени
горел экран, сколько раз его разблокировали, во сколько он погас последний раз вечером и
когда включился утром.

Шаги и сон приходят из Health Connect, если есть часы или браслет. Если их нет, сном
считается самая длинная ночная пауза без экрана — это оценка, и приложение честно называет
её именно так, а не «сном».

### Что значит «паттерн»

Человека сравнивают только с ним самим. Не с нормой сна, не со средним по стране, не с
рекомендациями ВОЗ — с его же последними неделями.

«Вчера экран погас на час позже обычного» имеет смысл, только если известно, что такое
*его* обычное. Поэтому первые дни приложение почти ничего не говорит: не с чем сравнивать.

### Кто придумывает фразы

Все числа и сравнения считает сервер обычным кодом — сколько минут, на сколько больше
обычного, в какие дни повторялось. Языковая модель получает уже готовые факты и только
превращает их в человеческую фразу.

Она не придумывает цифры и не ставит диагнозов. Под каждым разбором в приложении можно
раскрыть «На чём основано» и увидеть те самые факты.

### Что уходит с телефона

Уходит: минуты, количество разблокировок, время отхода ко сну, шаги. Плюс какими
приложениями и сколько минут пользовались — по имени пакета, чтобы отличить работу от
соцсетей.

Не уходит ничего из того, что *внутри*: ни переписки, ни содержимое экранов, ни
геолокация — приложение её вообще не запрашивает. Аккаунт анонимный, без почты и телефона;
постоянный идентификатор устройства хранится только как необратимый хеш.

Полный список разрешений — в [AndroidManifest.xml](android/app/src/main/AndroidManifest.xml),
и каждое используется.

## Что внутри

| | |
|---|---|
| **Утренний прогноз** | Одна фраза на день — на основе сна, активности, экранного времени |
| **Passivе трекинг** | Health Connect + UsageStats. Без ручного ввода |
| **Разбор дня / недели** | LLM-саммари с конкретными паттернами |
| **Чек-ин из шторки** | Три кнопки в уведомлении — открывать приложение не нужно |
| **Переустановка** | История и прогнозы сохраняются — телефон узнаётся по device hash |
