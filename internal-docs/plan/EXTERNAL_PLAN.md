## 1. AppMetrica

**Уже есть:** `onboarding_step`, `onboarding_permission`, `onboarding_finished`, `first_forecast_shown`, `morning_forecast_view`, `checkin_done` (последние два не выпущены, AN-03).

**Добавить (AND-01):**
- показ карточек и чипов (impressions);
- `notification_shown` с типом (утро, вечер, разбор);
- нажатие кнопок в шторке (отметка, «Совпало?»);
- `app_open` с источником (иконка, пуш, виджет);
- события Дня 0: `screen_view`, `tap_checkin_emotion`, `tap_day_review_*`;
- свойства при завершении онбординга: `has_usage_stats`, `has_health_connect_data`.

**Настроить в кабинете (AN-07):**
- воронка: установка, онбординг, разрешения, первый прогноз, первый чек-ин;
- ретеншн по событию `checkin_done` и по `morning_forecast_view`;
- трекинговые ссылки на каждый канал и каждую гипотезу;
- отчёт по источникам.

Правило приватности: события без пользовательских данных.

## 2. Атрибуция и RuStore (AN-01, EX-06)

1. Миграция `015`: `users.source`, `users.campaign`.
2. `/register` принимает источник.
3. Приложение читает Install Referrer (RuStore, Google) и deep link при первом запуске.
4. Трекинговые ссылки AppMetrica для каждого канала.
5. RuStore: листинг, иконка 512, скриншоты, модерация. План в [RUSTORE_PLAN](../dev/RUSTORE_PLAN.md). Пока нет RuStore: отдельные посадочные `/tg`, `/direct` с меткой (EX-13).

## 3. Маркетинг (EX-08)

План из [SYNC_PREP](../competition/SYNC_PREP.md): бюджет 300 тыс. ₽ (ещё две порции по 300 тыс. по итогам).

- Волна 1: 90 тыс. ₽ в трёх гипотезах по 30 тыс. (решение D9 за владельцем).
- Гейт 13–16.11: канал с D7 ≥ 40% масштабируется, остальные режутся.
- Шаблон HADI на каждую гипотезу (EX-10), отчёт каждую среду.
- Креативы эмоциональные, ключи утилитарные (DS-07).
- Чек-лист GTM из 14 блоков (EX-11), CJM после установки (EX-12).

## 4. Юридическое (EX-05)

До запуска рекламы:
- политика обработки персональных данных (152-ФЗ);
- пользовательское соглашение;
- чекбокс согласия в онбординге;
- контакты владельца в листинге и на сайте;
- уведомление в РКН;
- ERID через ОРД для рекламы;
- без формулировок «лучший», «№1», «единственный»;
- медицинские обещания не делаем (продукт наблюдатель).
