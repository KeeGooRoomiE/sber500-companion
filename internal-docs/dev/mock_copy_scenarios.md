# Сценарии копирайтинга — 7 дней по мок-данным

Три точки касания в день:
- **Утро (~07:40)** — прогноз в HomeScreen + пуш-уведомление
- **Вечер (~20:30)** — пуш чек-ин (персонализированный текст)
- **Совет** — контекстный, не случайный пул

Каждый день: вариант **A** (основной), **B** (мягкий/короткий), **C** (прямой/без обёртки).

## Правила тона (вытащить в system prompt)

| Ситуация | Правило |
|----------|---------|
| feel=hard 2-й день подряд | Убрать советы, только признание: «вижу, что тяжело» |
| Положительная аномалия | Назвать конкретно (68мин без телефона), не «ты молодец» |
| Плохие показатели | Одно действие, не список из трёх |
| Первый день данных | Не давать прогноз, только «собираем данные, завтра будет первый прогноз» |
| Выходные | Не давать рабочих советов, тон мягче |
| Повтор хорошего паттерна | Назвать его по имени: «это работает, повтори» |
