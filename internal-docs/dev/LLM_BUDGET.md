# LLM Budget — cloud.ru Foundation Models

Проверено: 2026-09-24. Источник: [каталог cloud.ru](https://cloud.ru/ru/products/evolution-foundation-models).

## Используемая модель

**GigaChat-3-Pro** (`ai-sage` на cloud.ru).  
Env: `LLM_MODEL=GigaChat-3-Pro`, `LLM_BASE_URL=https://api.cloud.ru/v1`.

> ⚠️ Старое имя `GigaChat-Pro` — устаревшее, API его не принимает. Только `GigaChat-3-Pro`.

## Стоимость одного вызова (утреннее уведомление)

Один вызов = генерация утреннего прогноза для одного пользователя.

| Параметр | Значение |
|---|---|
| Input | ~700 токенов (системный промпт + 7 дней данных + средние) |
| Output | ~80 токенов (2 предложения, лимит MaxTokens=100) |
| Input стоимость | 700 × 73.03 / 1 000 000 = **0.0511 ₽** |
| Output стоимость | 80 × 176.39 / 1 000 000 = **0.0141 ₽** |
| **Итого** | **~0.065 ₽ / уведомление** |

## Расход бюджета 50 000 ₽

Итого вызовов: 50 000 / 0.065 = **~769 000 вызовов**.

| DAU | Дней | Срок |
|---|---|---|
| 1 000 | 769 | ~2.1 года |
| 5 000 | 154 | ~5 месяцев |
| 10 000 | 77 | ~2.5 месяца |
| 50 000 | 15 | — |

**Для конкурса (Stage 1 = 2026-10-15):** при 1 000 DAU бюджет покрывает весь конкурс с запасом в 760+ дней.

## Альтернатива: GigaChat3-10B (дешевле, качество ниже)

| Параметр | Значение |
|---|---|
| Стоимость вызова | ~0.0095 ₽ |
| Вызовов за бюджет | ~5 200 000 |
| При 10 000 DAU | 520 дней (~1.5 года) |

Подходит для фоновых/вспомогательных задач, не для основного прогноза.

## Контроль расходов

- `morning_messages` хранит `prompt_tokens + completion_tokens + latency_ms` для каждого вызова
- Мониторинг: `SELECT date_trunc('day', generated_at), SUM(prompt_tokens + completion_tokens) FROM morning_messages GROUP BY 1 ORDER BY 1 DESC`
- Порог алерта: если дневной расход > (бюджет / 30 дней) — что-то пошло не так

## Когда пополнять

При 1 000 DAU ежемесячный расход: 1000 × 30 × 0.065 = **1 950 ₽/мес**.  
Текущий бюджет 50 000 ₽ истечёт примерно через **25 месяцев** при 1k DAU.
