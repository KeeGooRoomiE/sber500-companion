# Исследование: шаблонность утренних текстов между днями

**Дата:** 2026-10-31. **Данные:** 1097 боевых утренних текстов, 54 пользователя, 1030 пар «соседние дни одного человека» (разрыв ≤2 дней). Идентификаторы хэшированы, dev и mock исключены. **Воспроизведение:** `bash tools/usage-rd/run.sh export && bash tools/usage-rd/run.sh repeat` (данные только локально, в git не попадают).

**Зачем.** В кастдеве 3 из 8 респондентов назвали «одинаковые сообщения» причиной удаления приложения. Аудит качества мерил шаблонность по одному тексту (около 3%), но не повторы **у одного человека подряд**.

## Метод
Сравниваю сходство текстов двух групп: (а) соседние дни одного пользователя; (б) случайные пары разных пользователей в пределах трёх дней (это фон: насколько похожи любые два текста продукта). Числа заменены на `N`, чтобы сравнивать шаблон, а не цифры. Две меры: J (доля общих трёхсловий) и R (посимвольное сходство по `difflib`). Если (а) выше (б), человек видит повторы именно себе; если равно, продукт звучит одинаково для всех.

## Результаты

| | n | J медиана | R медиана | R p90 | R ≥ 0.8 |
|---|---|---|---|---|---|
| соседние дни одного пользователя | 1030 | 0.04 | 0.48 | 0.73 | **6%** |
| разные пользователи, та же неделя (фон) | 608 | 0.02 | 0.41 | 0.53 | **0%** |

По периодам промта (R медиана, доля R ≥ 0.8): до 02.10 0.47 / 0% (n=48); 02–08.10 0.56 / 8% (n=196); с 08.10 0.45 / 6% (n=786).

Застывшие конструкции (по всем 1097 текстам):
- вторая фраза начинается с «после таких дней…» в **54%** текстов (22% «обычно», 21% «у…», 11% «утро…»);
- первая фраза: «вчера был/было…» в основном, «вчера был день» у 23%;
- вторые предложения целиком совпадают у 19% текстов (903 уникальных из 1009).

По пользователям (45 человек с ≥5 парами): средний R на человека, медиана 0.47; **у 40% пользователей средний R ≥ 0.5**; самый «одинаковый» пользователь 0.73 (15 пар).

Попутная проверка боевого промта v4 (датированные тексты):
- «личные закономерности» («у тебя обычно…»): до 08.10 **79%** (230 из 292), с 08.10 **5%** (39 из 805). Результат лаборатории (73% → 0%) подтверждён на боевых данных, лаборатория работает как индикатор.
- формат в бою: 2 предложения у 85% текстов (935), одно у 8% (88), три и больше у 7% (74). Совпадает с лабораторией (~11% без «что дальше»).

## Выводы
1. **Повторы есть, но чаще структурные, чем дословные.** Дословно-близких пар (R ≥ 0.8) 6% против 0% у разных людей: примерно каждый 16-й день человек получает почти тот же текст, что вчера. Это настоящий пользовательский повтор.
2. **Основная причина шаблонности глобальная:** одна рамка «Вчера был… После таких дней обычно…» держит больше половины текстов. Фон между разными людьми (R 0.41) уже высокий, поэтому даже без личных повторов продукт звучит одинаково.
3. **Блок «что ты уже писал» (02.10) эффект не доказал:** до 02.10 только 48 пар, сравнение неустойчиво.
4. Промт v4 (08.10) решил ровно то, ради чего делался (личные закономерности 79% → 5%), и этот результат переносится с лаборатории на бой.

## Кандидаты в пакет правок (без выкатки, решение за владельцем)
1. **Разнообразие каркаса.** Сервер случайно выбирает для дня одну из 4–5 разрешённых конструкций второй фразы («к вечеру обычно…», «в такие дни чаще…», «если сравнить с…» без «если»-условий и без «у тебя») и передаёт её в блок «Тон/Стиль». Цель: снизить долю «после таких дней…» с 54% до ~25%. Требует кода в `buildPrompt` и A/B в лаборатории (`tools/prompt-lab`) на метрике «доля повторов R ≥ 0.8».
2. **Страж повторов.** Если новый текст слишком похож на вчерашний (R ≥ 0.8), один раз перегенерировать с указанием назвать другой факт. Цена: +~6% вызовов к утренней генерации (заодно небольшой плюс к вызовам). Закрывает именно пользовательский повтор.
3. **Метрика на дашборд аудита:** доля пар с R ≥ 0.8 (сейчас 6%) и доля текстов с «после таких дней…» (сейчас 54%).

## Ограничения
- Сходство лексическое, без смысла: два текста о разном с общим каркасом дают высокий R.
- Пользователей мало (54), у 12 из них больше 30 текстов, они сильнее влияют на средние.
- Эффект блока «что ты уже писал» не оценён из-за малой выборки до 02.10.
