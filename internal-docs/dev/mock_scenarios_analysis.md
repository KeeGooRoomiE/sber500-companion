## Паттерны, которые LLM должен отслеживать (7 дней достаточно)

### P1. Нисходящий сон → ранний алерт
```
Пн 432 → Вт 360 → Ср 298 (feel=hard)
```
На третий день это критическая ситуация. Алерт нужно давать *утром среды* (второй день подряд ниже нормы), не ждать пока станет hard.

### P2. Соцсети как эскейп
```
feel=hard → Instagram #1 (68min), YouTube #2 (57min)
feel=ok  → Telegram #1, менее 40min суммарно соцсетей
```
При `feel=hard` Instagram/YouTube вылезают наверх. LLM может *предсказывать* тяжёлый день по паттерну приложений ещё до чек-ина.

### P3. Шаги = лучший предиктор feel
```
steps > 7000 → feel=ok (Пн, Чт)
steps < 3000 → feel=hard/meh (Вт 3100/meh, Ср 1820/hard)
```
Самая прямая корреляция в этих данных. Сильнее, чем сон.

### P4. Не зарядил телефон → маркер плохого вечера
```
battery_morning=61% (Ср) — единственный день <80%
Тот же день: last_unlock=01:09, feel=hard, unlocks=91
```
Если утром заряд <75%, это постфактум-маркер: «вчера что-то пошло не так вечером».

### P5. Первый unlock позже wakeup → хороший знак
```
Вс: wakeup(HC)=05:43, first_unlock=06:51, дельта=68мин
```
Человек проснулся и *не стал сразу смотреть телефон*. Это поведение нужно замечать и хвалить — положительное подкрепление работает лучше, чем запреты.

## Сценарий «умный вопрос» (профиль пользователя)

На основе этих данных LLM после 3–4 дней мог бы спросить:

> «Я заметил, что в четверг у тебя было 8500 шагов — это лучший день недели. Ты был в каком-то конкретном месте или просто вышел погулять?»

Это и есть контекстный вопрос из профиля — не анкета при онбординге, а разговор на основе реальных данных. Та же механика для WiFi:

> «Сегодня ты весь день на одном WiFi и сделал 1820 шагов. Это домашняя сеть? Настрою, чтобы отличать "дома" от "не дома".»

## Вывод: что нужно в промпте

LLM получает на вход:
```json
{
  "last_7_days": [ /* daily_data rows */ ],
  "yesterday_checkin": { "feel": "hard", "tags": [] },
  "weekly_averages": { "screen_min": 256, "sleep_min": 411, "steps": 5290 }
}
```

Ключевые инструкции в system prompt:
1. Сравнивать вчера с личными средними, не с «нормой здорового человека»
2. Называть конкретные приложения по имени (резолвить package → label)
3. Давать одно действие, не список
4. Замечать положительные отклонения, не только негативные
5. Если 3 дня подряд ухудшение — менять тон на более мягкий, не давить
