## Маркетинговый юнит

- Продуктовый ментор — продукт, метрики, core loop
- Маркетинговый ментор — стратегия, гипотезы, разбор результатов
- Маркетинговый специалист — настройка и ведение кампаний
- Общий чат: я + продуктовый ментор + маркетинг. Все решения там.
- **Доступ в рекламные кабинеты — только read.** Вижу кампании и статистику, правки идут
  через специалиста.

**Куда можно лить бюджет:** Яндекс Директ (поиск + РСЯ), Telegram Ads, мобильное приложение
(больше настроек, требует мобильной аналитики — у нас AppMetrica есть).
Без настроенной аналитики результаты к зачёту не принимаются.

**Модерация креатива:** юнит → согласование внутри юнита → проверка Сбера (минимум 1 рабочий
день) → модерация площадки. **Закладывать день минимум.**
