# Пакет правок: кандидаты из исследований (сбор на начало следующей недели)

**Статус:** ничего из этого **не выкачено и не применено**. Всё лежит как кандидаты с доказательствами. Для каждого пункта указаны источник (документ с данными), усилия и что требует решения владельца. Приоритет: **П1** сначала (риск или дёшево и снимает пробел), **П2** после, **П3** по желанию.

## Сначала решения, без которых остальное вслепую
| Вопрос | Почему важно | Источник |
|---|---|---|
| Как организаторы считают «обращения на DAU» (все LLM-вызовы, только по инициативе, учитывается ли фон и вызовы для не-DAU) и как определяют DAU | Меняет текущее значение вдвое (2.44 против 1.38 на DAU) и может срезать DAU на треть (36% DAU-дней это только запрос утра) | RESEARCH_ANTIFRAUD, RESEARCH_HEAVY_USERS |
| Текст методики антифрод-аудита из Положения | Репетиция идёт по нашим требованиям, не по методике | RESEARCH_ANTIFRAUD |
| Тексты и контакты помощи для кризисных фраз (нужен профильный специалист) | Без этого вариант A по кризисам не реализовать | RESEARCH_REDTEAM |
