## Q1 — Методика подсчёта вызовов (КРИТИЧНО)

Считается ли вызов компонента, результат которого пользователь получит позже?

**Конкретный пример:** ночная генерация в 4:00 (батч по всем активным пользователям),
доставленная пуш-уведомлением в 7:40. Пользователь не открывал приложение в 4:00,
он открыл уведомление в 7:40.

- Вариант A: считается по моменту вызова (4:00) — тогда батч-архитектура легитимна.
- Вариант B: считается только при активном взаимодействии (7:40) — тогда генерация
  должна происходить в момент открытия уведомления/приложения.

Ответ определяет архитектуру бэкенда.
