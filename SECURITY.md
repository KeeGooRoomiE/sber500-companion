# Безопасность

Companion — работающий сервис: у приложения есть живые пользователи, а на сервере
лежат их поведенческие данные. Поэтому об уязвимостях лучше сообщить приватно, а не
публичным issue.

## Как сообщить

Через **Private vulnerability reporting** на вкладке
[Security](https://github.com/KeeGooRoomiE/sber500-companion/security) этого
репозитория — отчёт видим только мейнтейнеру.

Пожалуйста, не открывайте публичный issue до того, как проблему закроют.

## Что полезно приложить

- Что затронуто: приложение, API или инфраструктура
- Шаги воспроизведения или запрос
- Что удалось получить — доступ к чужим данным, обход аутентификации, что-то ещё

## Что в зоне внимания

| В зоне | Вне зоны |
|---|---|
| API `api.94-183-236-169.sslip.io` | Отчёты сканеров без подтверждённого воздействия |
| Android-приложение (`ru.keegoo.companion`) | Отсутствие security-заголовков на статическом лендинге |
| Аутентификация и изоляция данных между пользователями | Social engineering, физический доступ к устройству |
| Утечка персональных данных | Нагрузочные тесты и DoS — не проводите их по живому серверу |

## Чего ожидать

Проект ведёт один разработчик, поэтому без SLA: ответ в разумный срок, фикс по
серьёзности. Вознаграждения за находки нет — сказать об этом честно правильнее, чем
промолчать.

Как обрабатываются сами пользовательские данные — в
[политике конфиденциальности](https://keegooroomie.github.io/sber500-companion/privacy.html).
