# followup-rd

Задача #7 из `internal-docs/ops/LLM_EVAL_TASKS.md`: длинные цепочки follow-up, скоринг
связности/дрейфа — найти, где деградирует, лимиты глубины.

## Структурная находка перед стартом

В проде follow-up **не цепочка**: `backend/internal/llm/followup.go::BuildFollowup` каждый
раз грузит заново только оригинальный инсайт+данные, без памяти о предыдущих follow-up-ответах
(явный анти-дрейф дизайн по комментарию в коде). Каталог закрыт — максимум 4 чипа на
day-инсайт (why/context/prev_days/similar), свободного ввода нет.

Этот инструмент **симулирует** гипотетическую цепочку с памятью (следующий вопрос видит все
предыдущие Q&A), чтобы: (а) проверить, что нынешний мелкий дизайн безопасен, (б) найти, на
каком шаге деградация начинается, если когда-нибудь добавим память/свободный ввод (например,
«спроси о своих данных»).

## Пайплайн

1. **fetch** — реальный day_review (текст, уже показанный юзеру) для 5 юзеров из
   `tools/signal-rd/data/users.json` (переиспользует их дневные данные). → `data/reviews.json`
2. **chain** — для каждого юзера: 4 реальных вопроса каталога в реальном порядке, затем 3
   вопроса ЗА пределами каталога (спекулятивный/retrieval/pushback — специально давят на
   дрейф, советы, самопротиворечие). Каждый шаг видит всю историю цепочки. Один вызов на шаг,
   последовательно. → `data/chains_<model>.json`
3. **drift** — judge оценивает ВСЮ цепочку целиком (не по шагам отдельно — видит cross-step
   противоречия) по 4 флагам: совет / галлюцинация / противоречие своим же прошлым ответам /
   дрейф от данных. → `data/drift_<judge>_<источник>.json`

## Запуск

```bash
bash tools/signal-rd/run.sh fetch 5     # если ещё не собрано
bash tools/followup-rd/run.sh fetch

bash tools/followup-rd/run.sh chain --model gigachat-3-pro
bash tools/followup-rd/run.sh drift --judge gpt-5.1 --from chains_gigachat-3-pro.json
```

Без параллелизма — ключ общий с другими прогонами, см.
`internal-docs/ops/LLM_SPEND_GUARDRAILS.md`. `data/` в `.gitignore`. Результаты и выводы —
в `internal-docs/research/llm-quality/`.
